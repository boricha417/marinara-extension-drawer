# 확장 서랍 1.4.0 (Marinara Engine 확장)

Marinara Engine 개인 확장입니다. (2.4.x ~ 2.5.1까지 호환 확인) 다른 확장들이 화면 곳곳에 띄우는 **런처 아이콘을 한 서랍에 모아 줍니다.** 확장을 여러 개 쓰면 화면 구석마다 떠 있는 버튼이 채팅을 가리는데, 그 버튼들을 제자리에서 숨기고 서랍 안의 타일로 대신 누를 수 있게 합니다. 새로 설치한 확장의 아이콘도 자동으로 담기고, 자동으로 안 잡히는 것은 직접 담을 수 있습니다.

## 들어가는 자리

**서랍 위치**는 설정에서 두 가지 중 고릅니다.

- **상단 메뉴** (기본) — 상단 바의 버튼 줄에 서랍 버튼이 들어갑니다. 자리는 화면 상태에 따라 순서대로 고릅니다. 상단 바가 숨겨진 모바일 채팅방에서는 채팅 툴바의 `⋯` 버튼 바로 왼쪽, 모바일 확장의 `∨` 버튼이 있으면 그 뒤, 그 밖에는 상단 왼쪽 컨트롤(채팅·홈) 끝입니다. `⋯` 옆에 설 때는 그 버튼의 모양을 그대로 따라가 테마와 어울립니다.
- **아이콘 띄우기** — 화면 위에 떠 있는 버튼이 되고, 끌어서 아무 데나 둘 수 있습니다.

서랍 버튼에는 담긴 아이콘들의 **알림 배지 합계**가 표시됩니다. 원본 런처에 배지(숫자·점)가 있으면 서랍의 타일과 버튼에도 그 수가 뜹니다.

## 서랍 패널

버튼을 누르면 타일 그리드가 열립니다. 타일을 누르면 원래 확장의 런처를 누른 것과 똑같이 동작합니다.

| 머리 버튼 | 설명 |
| --- | --- |
| `+` 직접 담기 | 픽 모드가 켜집니다. 화면에서 담고 싶은 아이콘을 클릭하면 담기고, Esc로 취소합니다. |
| 톱니 설정 | 아래 설정 화면으로 들어갑니다. |

## 설정

| 묶음 | 항목 |
| --- | --- |
| 서랍 위치 | 상단 메뉴 / 아이콘 띄우기(이동 가능) |
| 수집 | **화면 고정 아이콘 자동으로 담기** 체크. 화면에 고정되어 떠 있는 작은 클릭 요소(14~170px)가 1.5초 이상 유지되면 자동으로 담습니다. 홈 화면 아이콘처럼 떠 있지 않은 것은 **직접 담기**로 추가합니다. |
| 담긴 아이콘 | 위로/아래로 순서 바꾸기, **서랍에서 빼기**. 뺀 아이콘은 원래 자리로 돌아가고 "제외한 아이콘" 목록에 들어가 다음 스캔에서 다시 담지 않습니다. |
| 제외한 아이콘 | **다시 담기**를 누르면 다음 스캔부터 다시 자동으로 담습니다. |

직접 담은 아이콘은 소유 확장이 꺼지거나 지워지면 타일에 **애드온에 없음**이 표시되고 그리드에서 숨겨집니다. 설정에서 빼면 됩니다.

## 동작 방식

- 원본 런처는 **옮기지 않고 제자리에서 숨깁니다**(`visibility: hidden`). 크기와 위치가 유지되므로, 런처 위치를 기준으로 패널을 띄우는 확장(API 잔액 위젯 등)도 깨지지 않습니다.
- 타일을 누르는 동안 숨긴 원본을 **타일 자리로 잠시 옮겨** 두었다가 돌려놓습니다. 그래서 런처를 누르면 패널이 열리는 확장의 패널이 서랍 옆에서 열립니다. 클릭만으로는 드래그형 런처의 저장 위치가 바뀌지 않는 것을 확인한 방식입니다.
- 클릭은 실제 포인터 이벤트를 복제해 원본에 전달합니다. 원본이 눌림 상태를 감지하는 확장도 그대로 동작합니다.
- Shadow DOM 안에 런처를 둔 확장도 지원합니다. 이때는 호스트 전체가 아니라 안쪽 런처만 숨깁니다.
- 스캔 주기는 화면 변화에 맞춰 조절됩니다. 변화가 없으면 1.2초에서 6초까지 느려지고, 새 요소가 생기거나 창 크기가 바뀌면 바로 깨어납니다. 탭이 숨겨져 있으면 스캔을 쉽니다.
- 설정과 담긴 목록은 확장 전용 서버 저장소(`marinara.storage`)에 저장되어 어느 기기에서 열어도 같습니다.

## 알아둘 점

- **담기지 않는 것** — 앱 자체의 팝업·메뉴·툴팁·대화상자, 화면 폭 전체를 차지하는 요소(퀵 팔레트의 미니 탭 등), 버튼이 둘 이상 든 툴바 전체. 픽 모드에서 툴바 전체를 고르면 "담을 수 있는 아이콘이 아니에요"가 뜹니다.
- 한 번도 화면에 그려진 적 없는 아이콘은 타일을 눌러도 실행할 수 없어 "원래 화면에 한 번 들어갔다 와주세요"가 뜹니다.
- 원본 확장이 창 크기가 바뀔 때 런처 위치를 기준으로 패널을 다시 놓으면, 그 순간에는 패널이 원래 런처 자리로 갈 수 있습니다.
- `⋯` 버튼이나 `∨` 버튼의 모양·이름은 엔진·다른 확장의 것이라, 바뀌면 그 자리만 다음 후보로 넘어갑니다.
- 같은 줄에 아이콘을 두는 다른 확장(익명 커뮤니티의 "채팅 툴바 아이콘" 모드 등)과는 앞뒤 순서만 지키고 바로 옆에 붙이려 들지 않습니다. 붙이려 들면 서로 자리를 다퉈 깜빡입니다.
- 개발용 플래그: 브라우저 저장소에 `exd-always-scan=1`을 두면 숨겨진 탭에서도 스캔하고, `exd-debug=1`을 두면 `window.__exdScanStats`에 스캔 통계가 쌓입니다. 보통은 필요 없습니다.

## 확장이 기대는 화면 표식

- 상단 바: `header[data-component="TopBar"]`, `.mari-topbar-left-controls`, `nav[data-tour="panel-buttons"]`
- 채팅 툴바 `⋯`: `button[aria-haspopup="menu"]` + `svg.lucide-ellipsis`(또는 aria-label "More options")
- 모바일 확장 `∨`: `#marinara-mobile-actions-button`
- 소유 확장 판별: `/api/personal-extensions/{id}/page-style.css` 스타일시트에 규칙 셀렉터가 있는지, 활성 목록은 `GET /api/personal-extensions/runtime/client`

엔진이 이 구조를 바꾸면 해당 자리만 손보면 됩니다.

## 설치

1. **설정 → 고급 → 위험 구역**에서 "외부 확장 가져오기 허용"을 켭니다.
2. **설정 → 애드온 → 외부 확장**에서 이 저장소의 zip 또는 폴더(`manifest.json`, `extension.js`, `extension.css`)를 가져옵니다. GitHub 확장 관리자 확장을 쓰면 저장소 주소를 등록해 업데이트도 받을 수 있습니다.
   설치용 zip은 저장소에 올려 둔 `확장 서랍_v1.4.0.zip`입니다(파일을 열고 **Download** 버튼). 저장소 전체를 "Download ZIP"으로 받으면 폴더가 한 겹 더 있어 바로 설치되지 않습니다.
3. 가져온 확장은 꺼진 상태로 들어옵니다. 코드 해시를 확인하고 **승인 → 활성화**합니다. 코드가 바뀔 때마다 다시 승인해야 합니다.

이 확장은 `marinara.extension` 종류로, 마리나라 페이지 안에서 그대로 실행됩니다(full page access). 다른 확장의 요소를 숨기고 대신 눌러 주는 일을 하므로 이 권한이 필요합니다. 코드를 확인한 뒤 승인하세요.
